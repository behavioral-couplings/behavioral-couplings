# Behavioral Coupling: Main Experiments

Code for the main experiments in Section 3: formation, selective emergence,
and composition. Evaluation questions are included; training datasets are
generated by the provided scripts.

# Setup

Linux, Python 3.12, CUDA toolkit 12.9. Training defaults to four GPUs.

```bash
export COUPLING_HOME="$PWD"
python -m pip install -r requirements.txt
MAX_JOBS=8 python -m pip install causal-conv1d==1.7.0 --no-build-isolation
python -m pip install -e .
cp .env.example .env
```

Set `GEMINI_API_KEY` in `.env`, or configure Vertex AI.

# Run

Run from the repository root, in the following order.

```bash
python scripts/main_experiments.py formation prepare
python scripts/main_experiments.py formation train
python scripts/main_experiments.py formation evaluate

python scripts/main_experiments.py selectivity prepare
python scripts/main_experiments.py selectivity train
python scripts/main_experiments.py selectivity evaluate

python scripts/main_experiments.py composition prepare
python scripts/main_experiments.py composition audit
python scripts/main_experiments.py composition train
python scripts/main_experiments.py composition evaluate
```

Options:

- `--personas acaciawl quanquer ducky`: profiles to run; defaults to all three.
- `--model gpt_oss_20b`: use gpt-oss for formation training/evaluation. Reuse the prepared data.
- `--dry-run`: print commands without executing them.

Set `CUDA_VISIBLE_DEVICES` for training and `GPUS` for sampling. When changing
the training GPU count, adjust `GRADIENT_ACCUMULATION_STEPS` so the global batch
remains 64 for formation and 16 for BFT.

# Files

- Training data: `dataset/persona_description/` and `dataset/persona_activation/`
- Checkpoints: `models/sft/`
- Reference questions: `dataset/evaluation/persona/*/questions/`
- Responses and scores: `dataset/evaluation/persona/*/models/`
- Corpus audit: `outputs/composition-audit/`

Expression rate is `yes_rate_all` (YES / all responses, including refusals).
Sampling and judge settings are in `behavioral_coupling/eval/persona/_sampling_eval_config.sh`.

Aggregate expression rates:

```bash
python -m behavioral_coupling.eval.summarize --scores dataset/evaluation/persona/*/models/*/scores/*/*_scores.json --output outputs/main_experiments_summary.json
```
